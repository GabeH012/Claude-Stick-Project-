# Claude-Stick-Project-
## Stick Story Animation plugin

This repo is a Claude Code plugin marketplace with one plugin, `lumenstick-stick-story`
(in `plugins/lumenstick-stick-story`): long-form 16:9 stick figure story videos built with Remotion.

It is enabled automatically for this project via `.claude/settings.json`. To install it elsewhere:

    /plugin install lumenstick-stick-story --marketplace GabeH012/Claude-Stick-Project-
